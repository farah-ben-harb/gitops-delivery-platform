# Security Policy

## Security expectations

- Do not commit live secrets or private keys.
- Keep secret examples in placeholder files only.
- Use Kubernetes secrets, sealed secrets, or external secret management for real values.

## Reporting a vulnerability

If you find a security issue:

1. Avoid posting exploit details publicly.
2. Identify the affected manifest or overlay.
3. Describe how the issue can be reproduced safely.
4. Do not include real credentials in the report.
