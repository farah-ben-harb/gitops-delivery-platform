# Contributing

Thanks for improving this repository.

## Recommended workflow

1. Sync `main`.
2. Create a focused branch.
3. Keep one logical change per commit.
4. Validate manifests locally before opening a pull request.
5. Explain what changed and why in the PR description.

## Branch naming

- `feat/<short-description>`
- `fix/<short-description>`
- `docs/<short-description>`
- `ci/<short-description>`
- `chore/<short-description>`

## Commit messages

Prefer Conventional Commits when practical:

- `feat(scope): add new capability`
- `fix(scope): correct a bug`
- `docs(scope): improve documentation`
- `ci(scope): update workflow`
- `chore(scope): update dependencies`
